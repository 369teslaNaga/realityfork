# Contributing to RealityFork

Thank you for helping build a free, inspectable science playground.

1. Open an issue describing a small, reproducible change before undertaking a large redesign.
2. Work from a feature branch. Keep source static, dependency-free, and GitHub Pages compatible.
3. Run `npm run check` and `npm test`. Test at 360 px width, keyboard focus, desktop and mobile as applicable.
4. Mark measured data, model predictions, synthetic examples and known limitations explicitly. Scientific claims require a numerical test or reference.
5. Use short, permission-cleared test footage only. **Never submit another person's private video, API keys or production data.**
6. Propose updates to the versioned experiment JSON format rather than silently breaking saved experiments.

Useful first contributions: reproducible ball-video fixtures under a permissive license, improved color tracking, robust frame seek cancellation, WebM browser-compatibility notes, motion-unit uncertainty visualization, Tamil/English localization.
