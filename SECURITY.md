# Security policy

RealityFork is an experimental local-first browser application. **Do not publicly disclose exploitable vulnerabilities before maintainers have an opportunity to respond.** Use GitHub's private vulnerability reporting if enabled, or create an issue requesting private contact information without posting exploit details.

We do not operate a video upload server. Do not add third-party video requests, user analytics, tracking scripts, or remote API dependencies without an explicit design review and prominent privacy disclosure. Treat imported JSON and browser file objects as untrusted.
