# Roadmap (feature requests welcome)

## v1.0 beta — initial public source release

- [x] Six named functional modes on one professional responsive interface
- [x] Transparent observed / modeled labels
- [x] Video RGB tracking + manual observation marks
- [x] 2D physics, trajectory chart, derived-data export
- [x] Local PNG / WebM support when browser API allows
- [x] Unit tests + browser smoke tests + CI + GitHub Pages workflow

## v1.1 — make the *evidence* stronger

- [ ] Editable object-track corrections and on-canvas point review
- [ ] Camera-plane calibration wizard with measured reference segments
- [ ] Uncertainty bounds and error bars on graph derivatives
- [ ] Improved treatment of duplicate colors, object occlusion and changing light
- [ ] Dataset fixtures with public-domain / permissive licenses and measurable ground truth
- [ ] Cross-browser continuous E2E tests (Chromium, Firefox, WebKit)

## v1.2 — independent reproducibility

- [ ] Portable validation reports and dedicated scientific benchmark tests
- [ ] Well-documented experiment schema v2 with migrations
- [ ] Exportable single HTML replay capsule (user-explicit, privacy reviewed)
- [ ] More numerically accurate integrators and meaningful model comparisons
- [ ] Localization contributions (Tamil, English and others)

## Long-term (research, not promises)

- [ ] Opt-in optional on-device segmentation model for more objects
- [ ] Multiple object collisions with verified dynamics
- [ ] Better camera geometry and 3D measurements from suitable multi-view input
- [ ] Community-created physical experiment plugins and benchmark gallery

We do not claim to be the first or unique reverse-engineering system. Value will come from quality, trust, design and maintainability.
